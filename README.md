# Program for a Right Triangle's Hypotenuse


## Description
This program calculates the hypotenuse of a right triangle by asking the user for the two given sides.
## How to Run
Simply just play the program and input the 2 other sides of your right triangle, can be decimal. After that, it automatically calculates such and displays it. Do note that it only shows up to two decimal places.
## Input Needed
For the program to work properly, it must only be integers and decimals, as string nor any other data type isn't allowed and causes a program error.
## Sample Output
Enter the length of side a: 6.23
Enter the length of side b: 7.8
The hypotenuse is: 9.98
